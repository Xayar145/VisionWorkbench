# 第一版验证记录

验证日期：2026-10-19。

环境：Windows x64，.NET SDK 10.0.301，HALCON 24.11，OpenCvSharp 4.13.0.20260627。

执行 `scripts/check.ps1 -Configuration Release`，构建为 0 警告、0 错误，两组检查进程均退出 0。

## 集成检查

1. HALCON 区域分析：示例检测到 3 个区域。
2. 方案、图像资产保存和重开：检测结果一致。
3. 数量范围不符正常判定 NG，区别于执行异常。
4. 空区域正常返回数量 0 和 NG。
5. OpenCV 滤波与 HALCON 后续工具的混合执行。
6. HALCON 与 OpenCV 滤波只改变矩形 ROI 内像素。
7. 矩形 ROI 限制的尺寸测量：宽度为 100 像素。
8. HALCON 形状模板创建、定位及模板资产重开。
9. 工具注册、非法参数/ROI 拒绝、实际运行结果读取。
10. HTTP 工具接口：拒绝未认证请求，发现 7 个工具，认证后执行流程。
11. 两张图批量检测导出 CSV，保持当前工程的源图身份。
12. 取消后恢复就绪状态。
13. 本机模型协议桩：真实聊天客户端发起 3 次请求，修改阈值、执行 HALCON 流程，并把对应运行编号的真实结果返回协议桩。

## 界面检查

1. 真实 WPF 窗口显示工具列表、图像、叠加框及结果。
2. 接口修改参数后，界面同步；编辑后旧报告和叠加框失效。
3. 中文 AI 页面及最小窗口布局截图检查。

主界面截图见 [界面预览](images/workbench.png)。检查报告和其他截图由脚本生成到 `artifacts`，不提交运行缓存。

## 未验证项

未连接真实云模型或工业相机/PLC，未开展产线精度、吞吐量与长期稳定性测试。协议桩只验证客户端协议与工具执行链路，不代表真实模型的决策质量。
